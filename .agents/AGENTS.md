# Permanent Coding Rules & Guidelines

- Never create duplicate code.
- Never create duplicate imports.
- Keep imports at the top of the file.
- Keep every file production-ready.
- Follow Clean Architecture.
- Follow SOLID principles.
- Keep code modular.
- Keep functions small.
- Never break existing UI.
- Never change design unless instructed.
- Always test before reporting completion.
- Never say "completed" unless verified.
- Ensure 100% clean imports with zero missing symbols or red/yellow squiggle diagnostics.
- Always verify all imported models, functions, and types exist and are explicitly imported at top of file.
