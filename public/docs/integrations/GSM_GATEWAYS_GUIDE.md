# SIM & GSM Hardware Gateways — Zero Platform Charge Guide

SIM & GSM Gateways enable **Zero-Platform-Charge Calling** by routing AI Voice Agent calls through physical carrier SIM cards installed in Android smartphones, USB 4G LTE modems, or SIM Box hardware.

---

## 🎯 Role in Live Phone Calls & Purpose
Allows AI Voice Agents to place outbound calls and receive inbound calls using physical mobile SIM cards with unlimited calling plans, avoiding per-minute cloud telephony markup charges.

---

## 📌 Kahan Use Hoga? (Where Is This Used?)
- Used for high-volume sales campaigns, debt collection calls, and customer follow-up calls where saving per-minute call charges is critical.

---

## 💡 Real-World Voice Calling Example
- **Scenario**: Running a 10,000 minute outbound calling campaign in India or North America.
- **Execution**: The AI Agent routes calls through an Android smartphone running the Nexus GSM Gateway App with a Jio 5G / Airtel 4G SIM card. **Platform per-minute calling cost is ₹0.00 (100% Free)**.

---

## 🚀 Project me Kyu Zaroori hai? (Why Is This Critical?)
1. **100% Free Platform Calling**: Eliminates per-minute cloud telephony charges.
2. **Local Mobile Caller ID**: Higher call pick-up rate because callers see a familiar 10-digit mobile number.
3. **Multi-SIM Slot Management**: Easily map and route across multiple SIM cards.

---

## 🛠️ Step-by-Step Setup Instructions
1. **Select Hardware Type**: Choose Android Smartphone App, USB GSM Modem, or SIM Box Bank.
2. **Connect Device IP**: Input local device IP and port (e.g. `192.168.1.140:8080`).
3. **Map SIM Slots**: Assign SIM labels (e.g. `SIM Slot #1 Jio 5G`).
4. **Test Connection**: Click `Test Gateway Diagnostics` to verify ping response and 5G/4G signal strength.
